Sobre o projeto

CineNote é um projeto acadêmico feito para a disciplina de Extensão. A ideia foi construir, na prática, um site completo: uma tela para o usuário usar, um sistema por trás que guarda as informações com segurança, e testes automáticos para garantir que tudo continua funcionando a cada mudança.

CineNote — projeto acadêmico desenvolvido por Lucas Bordignon.
