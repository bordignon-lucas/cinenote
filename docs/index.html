CineNote

Um watchlist de filmes e séries: cadastre títulos, dê nota, marque favoritos e acompanhe o que já assistiu — com autocomplete de filmes e séries via TMDb.

Acessar a aplicação Ver código no GitHub

Sobre o projeto

CineNote é um projeto acadêmico desenvolvido ao longo das disciplinas de Extensão, com o objetivo de aplicar, na prática, o desenvolvimento de uma aplicação web completa: front-end, backend com API REST, banco de dados, testes automatizados e hospedagem em produção.

Funcionalidades

  • Conta individual: cada pessoa vê só os próprios títulos
  • Cadastro de filmes e séries com nota, tipo e status
  • Autocomplete de títulos com pôster, via API da TMDb
  • Ano de lançamento, gênero e diretor preenchidos automaticamente
  • Favoritos em carrossel arrastável, mantidos também na lista
  • Ordenação por nome ou ano, e busca por nome
  • Página de detalhes com sinopse e comentário pessoal
  • Edição e exclusão com confirmação
  • Testes automatizados (Jest + Supertest)
